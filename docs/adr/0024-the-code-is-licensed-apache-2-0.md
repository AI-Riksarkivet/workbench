# 0024. The code is licensed Apache-2.0 (2026-11-20)

**Status:** accepted. Source: the owner, 2026-11-20, in the grilling session: "yes apache 2".

## Context

The workbench and the design-system repository (`AI-Riksarkivet/ui`) are public and carried no licence, which grants
nobody the right to reuse them. The design system already holds components copied from Baby UI under Apache-2.0.

## Decision

The workbench and `AI-Riksarkivet/ui` are licensed Apache-2.0. Third-party code keeps its own licence and notice.

## Consequences

- Each repository carries a `LICENSE` file and names the licence in its package manifests.
- rask's licence is rask's own decision, recorded there.
